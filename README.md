# 🐾 Agenda Vet - Sistema de Agendamento Veterinário

A Agenda Vet é uma aplicação web desenvolvida para otimizar o gerenciamento e o agendamento de consultas e serviços em clínicas veterinárias. O projeto foi projetado para proporcionar uma experiência fluida, organizada e segura tanto para os clientes quanto para a gestão dos atendimentos.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

- **HTML5 & CSS3:** Estrutura e estilização moderna da interface web.
- **JavaScript (ES6+):** Linguagem de programação utilizada para a lógica da aplicação e manipulação dinâmica de elementos.
- **Zod:** Biblioteca para validação de esquemas e dados de formulários de forma rigorosa e segura.
- **OAuth:** Implementação de fluxo de autenticação para controle de acesso seguro dos usuários.
- **Git & GitHub:** Controle de versão e gerenciamento do código-fonte.

---

## 📝 Funcionalidades

A aplicação oferece os seguintes recursos:

- **Agendamento de Consultas:** Interface intuitiva para marcação, alteração e acompanhamento de horários de atendimento veterinário.
- **Validação de Dados:** Assegura que os dados inseridos nos formulários estejam corretos e seguros utilizando esquemas com Zod.
- **Autenticação Segura:** Gerenciamento de sessões e acessos de usuários por meio de fluxos com OAuth.

---

## 📚 Estrutura de Dados
- **Usuários:** Informações de autenticação e perfil gerenciadas via OAuth.
- **Agendamentos:** Registro de consultas contendo dados do tutor, do pet, serviço escolhido, data e horário.

---

## 🛠️ Configuração e Execução

Pré-requisitos:
- Um navegador web moderno (Chrome, Firefox, Edge, etc.).
- Opcional: Extensão *Live Server* do VS Code para executar localmente.

Instalação:

1. Clone o repositório:
   ```bash
   git clone [https://github.com/Lucasluvn/agenda-vet.git](https://github.com/Lucasluvn/agenda-vet.git)

2. Acesse a pasta do projeto:
   cd agenda-vet

3. Abra o arquivo index.html diretamente no seu navegador ou utilize o Live Server no VS Code para iniciar a aplicação localmente.
